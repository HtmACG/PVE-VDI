# 安全与边界

本文汇总 PVE VDI 的安全设计、凭据处理方式与当前版本的功能边界。

## 凭据与票据

- PVE 密码只经本地主进程发往目标 PVE API；
- 渲染进程无法读取密码、ticket 或 CSRF token；
- 会话票据仅保存在主进程内存中；
- 未勾选“记住凭据”时，密码不写入磁盘。

## 记住凭据（DPAPI）

勾选“记住凭据”后，密码使用 Electron `safeStorage` 加密保存：

- Windows 上底层为 DPAPI；
- 仅当前 Windows 用户可以解密；
- 加密文件位于本机应用数据目录。

## 渲染进程隔离

- 开启 `contextIsolation`，上下文与页面隔离；
- 渲染进程禁用 Node.js 能力；
- 只通过 preload 暴露的白名单 IPC 与主进程通信。

## 控制台桥接

- 控制台 WebSocket 由主进程桥接，仅监听 `127.0.0.1`；
- 回环路径使用随机短期令牌；
- PVE 控制台票据不会作为 URL 暴露给渲染进程；
- 不持久化控制台票据，关闭窗口即结束会话。

## 证书校验

- 默认允许 PVE 自签名证书，适配开箱即用的内网环境；
- 关闭“允许自签名证书”后执行严格 TLS 校验，证书必须被系统信任，否则登录失败。

## 功能边界

| 能力 | 当前状态 |
| --- | --- |
| QEMU / LXC 状态与电源操作 | 已支持 |
| QEMU 创建向导 | 已支持 |
| LXC 创建 | 未开放 |
| 快照查看 | 只读 |
| 快照创建 / 回滚 / 删除 | 未开放 |
| 虚拟机删除 | 未开放 |
| QEMU noVNC 控制台 | 已支持 |
| LXC / 节点 xterm.js 控制台 | 已支持 |
| QEMU 串口（serial0）终端 | 未单独暴露 |

## 仓库卫生

- 源码中的 PVE 地址与用户名默认值为空；
- `screenshots/` 与 `docs/screenshots/` 已加入 `.gitignore`；
- 提交前建议检查是否包含内网网段、证书指纹、集群名、虚拟机名或本地路径。
