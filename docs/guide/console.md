# 内置控制台

PVE VDI 内置两类控制台，分别对应图形界面与终端场景，均在独立原生窗口中打开。

## 两类控制台

| 对象 | 控制台技术 | 能力 |
| --- | --- | --- |
| QEMU 虚拟机 | noVNC / xterm.js | 图形桌面；客户机 SSH 终端（所有操作系统） |
| LXC 容器 | xterm.js | 流式终端输出 |
| 节点 Shell | xterm.js | 节点命令行 |
| 虚拟机文件面板 | SFTP | 仅客户机 SSH 可用时显示，浏览的是虚拟机内部 |

## 终端可用性判定

QEMU 串口控制台已取消，xterm.js 统一走客户机 SSH：

- **QEMU**：运行中即可打开。客户机 SSH（22 端口）可达时自动带出 IP；
  - 客户机 IP 来自 Guest Agent；探测走 `network-get-interfaces`，再并发敲 22 端口；
  - Guest Agent 不可用或探测不到时，打开终端会直接弹「客户机 SSH 凭据」窗口，手动填 IP / 端口 / 账号 / 密码；
  - 没装 sshd 也能打开窗口，但连接会提示端口拒绝或超时；
  - 探测在后台跑，不阻塞列表刷新。
- **LXC**：容器原生 pty，始终可用。
- **文件面板**：只连虚拟机自己的 sshd。LXC pty 终端没有客户机 SSH，文件面板直接隐藏并标注「不可用」，不会显示 PVE 本机目录；节点 SSH 窗口的文件面板仍是节点宿主机，但节点 SSH 回退到 PVE 通道时没有 SFTP，会标注「PVE 通道不支持」。

## noVNC 图形控制台

QEMU 虚拟机通过 noVNC 1.7 提供 RFB 图形控制台，支持：

- 发送 **Ctrl+Alt+Del**、**Ctrl+Alt+F1/F2/F12**、**Ctrl+Alt+Backspace**；
- **快捷键面板**：CAD、切换 TTY、粘贴本机剪贴板、全屏都收在一个入口里；
- 剪贴板双向读写；
- 适应窗口（画布填满窗口，不保留黑边）/ 原始尺寸；
- **本地光标**：VNC 画面内直接显示本机鼠标指针，不再使用远端下发的光标形状；
- **连接质量**：流畅（Q2/C9）、均衡（Q6/C6）、高清（Q9/C2）三档，切换立即生效；
- 全屏显示，支持 **F11** 快捷切换；
- 断线重连。

## xterm.js 终端

LXC 容器与节点 Shell 使用 xterm.js 6 及 FitAddon，支持：

- 流式输出与终端尺寸同步；
- 复制选区文本；
- 30 秒心跳保活。

## 独立窗口

noVNC 与 xterm.js 均在独立原生窗口中打开，可以单独移动、最小化、最大化或关闭，窗口使用自定义标题栏。

控制台窗口没有底部状态栏：连接方式（RFB / termproxy）、当前用户与连接状态都收进顶部工具栏，
标题栏下方整块区域全部留给控制台画面，最大化时 VNC 视口即窗口剩余高度。

控制台工具栏位于标题栏“已连接”状态旁，采用无边框、无底色的图标按钮。

控制台画面区域跟随软件的日夜配色：浅色模式使用浅色画布与白色标题栏，深色模式保留深色画布，
xterm.js 的配色（前景、光标、ANSI 色板）也会随主题即时切换。

## 连接与安全机制

控制台连接由主进程统一桥接：

- 主进程建立 **127.0.0.1 回环 WebSocket 桥**，渲染进程不直接连接 PVE TLS；
- 虚拟机 termproxy 隧道使用主进程的 `ws` 客户端，复用 PVE API 的 TLS agent（自签名证书可用）与登录 Cookie；
  连接失败会区分证书、票据（401/403）与接口不存在（404）等原因；
- 回环路径使用随机短期令牌，PVE 控制台票据不会作为 URL 暴露给渲染进程；
- 不持久化控制台票据；
- 关闭窗口会立即结束对应的控制台会话。

## 稳定性

xterm.js 会话涉及的几条链路都做了兜底，避免一个终端把整个程序拖崩：

- SSH 通道 / SFTP / SSH 连接对象都注册了 `error` 监听（EventEmitter 没有监听器时会直接抛异常）；
- 终端输出在主进程按 12ms 合批再发给渲染进程，`cat` 大文件、构建日志不会打爆 IPC；
- 终端尺寸适配只在宿主尺寸变化且目标行列数确实变化时才执行，避免 measure ↔ fit 反馈环卡死渲染进程；
- 终端写入、销毁、初始化失败都只影响当前标签；
- 主进程兜住未捕获异常与未处理 Promise，写入 `%APPDATA%\PVE VDI\logs\main.log`，不再弹出阻塞式错误框；
- 构建显式关闭标识符压缩，规避 xterm 6.0.0「已被上游压缩的 ESM 再压一次就崩」的已知问题
  （[xterm.js#5800](https://github.com/xtermjs/xterm.js/issues/5800)）。

## 当前限制

- QEMU 客户机必须运行 SSH 服务（Windows 装 OpenSSH Server，Linux 装 sshd），否则终端连不上；
- 文件面板需要客户机 SSH，LXC 容器终端暂不提供文件面板；
- 一个控制台窗口对应一个会话，多会话需打开多个窗口。
