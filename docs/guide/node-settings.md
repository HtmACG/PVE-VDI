# 节点设置

从节点卡片可以进入独立的节点设置页。设置页采用与软件“设置”一致的单页卡片布局，不再使用双侧边栏。

## 硬件信息

硬件分组展示服务器的物理信息：

- 服务器型号、主板；
- CPU 型号与 CPU 温度、温度传感器；
- 磁盘型号、容量、健康状态与 SMART 温度。

### 硬件数据的读取方式

服务器型号、CPU 温度与传感器通过一次性的 PVE termproxy 终端会话读取 DMI / hwmon / lm-sensors 数据：

- 需要 `root@pam` 与 `Sys.Console` 权限；
- 执行脚本固定且只读；
- 连接完成后立即关闭终端会话。

## 网络

网络分组读取物理网卡、网桥、VLAN 与 Bond，并支持完整的接口管理：

- 创建、编辑、删除接口；
- 写入待应用配置后，可选择应用或还原；
- 应用前会出现网络中断提示；
- 网络接口支持可视化端口卡片，可在设置中切换“卡片 / 列表”展示。

## DNS 与时间

- 编辑 DNS 搜索域与三组上游 DNS 服务器；
- 编辑节点时区与节点描述。

## 证书

证书信息只展示以下内容，不返回私钥或 PEM：

- 主体与签发者；
- 有效期；
- 指纹；
- SAN 主体备用名称。

## 存储库与防火墙

- APT 存储库参数查看；
- 防火墙参数、日志与系统日志查看；
- 防火墙规则与存储库为只读。

## 存储容量

查看节点上各类存储的容量：

- LVM、LVM-Thin；
- 目录存储；
- ZFS 存储池。
