# 集群成员与磁盘初始化

两块功能都属于写操作，风险等级高，页面上的破坏性按钮都加了二次确认或明确警示。

## 集群成员

入口在**集群**页左上的「集群成员」卡片。

| 元素 | 含义 |
| --- | --- |
| 本节点标记 | 当前连接进入的那个节点，没有移出按钮 |
| Ring0 地址 | 集群通信地址，加入集群时填的就是对端的这个值 |
| 票数 | 参与 Quorum 投票的权重 |

### 加入集群

「加入集群」**只在单机节点上可用**，已在集群中的节点按钮置灰——PVE 不允许已入集群的节点直接并入另一集群，必须先清掉 `/etc/pve/corosync.conf`。

需要填写：

| 字段 | 说明 |
| --- | --- |
| 对端节点地址 | 只填 IP 或主机名，不要带 `https://` 与端口 |
| 对端 root 密码 | 用于建立节点间 ssh 信任 |
| 建议主机名 | 选填，留空沿用对端的命名 |
| 集群指纹 | 选填，从对端「加入信息」里复制的指纹，填了可以防止连错集群 |

::: danger 加入会覆盖本节点配置
加入后本节点的用户、存储、防火墙、SDN 配置全部以对端集群为准，本地配置会被覆盖。操作前建议备份 `/etc/pve`，并确认节点上的虚拟机已关机。
:::

### 移出节点

悬停在非本节点那一行才会出现移出按钮。移出只改集群配置，**不会迁移该节点上的虚拟机**，也不会清空该节点的磁盘。

::: warning 移出前先迁走虚拟机
节点上的虚拟机若仍在运行，移出后集群将无法调度它们，且该节点会独立成一个单机 PVE，需要人工接管。
:::

## 磁盘初始化

入口在**节点**页 →「设置」→ 右侧「磁盘」卡片，每块磁盘行末的图标按钮。

「用途」列会标出磁盘当前去了哪里（`LVM`、`ZFS`、`目录` 等），没被任何存储占用的显示「空闲」。

### 六种初始化方式

| 方式 | 产出 | 适用 |
| --- | --- | --- |
| LVM-thin | 卷组 + thin 池 | 虚拟机磁盘的默认选择，支持快照与精简分配 |
| LVM | 卷组 | 传统块存储，不支持快照 |
| ZFS | ZFS 池 | 带校验，内存占用高，数据更安全 |
| 目录 | ext4 + 目录存储 | 用来放 ISO、备份或容器模板 |
| 仅 GPT 分区表 | 分区表 | 只想清掉旧分区，不建存储 |
| 擦除磁盘 | 空闲磁盘 | 彻底清掉分区表与文件系统签名 |

::: danger 全部不可撤销
初始化会重新分区，磁盘上的数据全部丢失，且无法恢复。操作前请再次核对设备路径——在 `/dev/nvme0n1` 和 `/dev/nvme1n1` 上看错一位，损失的是另一块盘。
:::

### 常见失败

| 提示 | 原因 |
| --- | --- |
| `disk already has a partition table` | 磁盘上有旧分区表，勾选「强制覆盖」 |
| `device is in use` | 磁盘仍被某个存储或虚拟机引用，先移除引用 |
| 操作长时间无响应 | 大容量机械盘擦除很慢，属正常现象，不要强行中断 |
