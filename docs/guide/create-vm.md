# 创建虚拟机

PVE VDI 支持两种创建 QEMU 虚拟机的方式：空白创建与从模板克隆。

## 空白创建

通过表单向导填写完整的虚拟机参数：

| 分类 | 可配置项 |
| --- | --- |
| 基本信息 | 节点、VMID、名称、OS 类型 |
| 计算资源 | CPU、内存 |
| 存储 | 磁盘、存储 |
| 安装介质 | ISO |
| 网络 | 网桥、VLAN |
| 其他 | Guest Agent、随机启动 |

名称为空时会直接校验失败并提示“请输入虚拟机名称。”

## 从模板克隆

基于现有模板创建虚拟机：

- 支持**完整克隆**与**链接克隆**；
- 可选择目标存储；
- 可勾选克隆完成后自动启动。

## 创建过程

- 创建过程会等待 PVE 任务完成，而不是只下发请求；
- 任务失败时返回 PVE 的原始错误信息，便于定位问题；
- 创建成功后自动打开新虚拟机的详情页。

## 边界说明

::: warning 当前范围
创建向导只创建 QEMU 虚拟机，LXC 容器的创建未在本版本开放。
:::
