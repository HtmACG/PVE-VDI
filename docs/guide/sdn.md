# SDN 网络

对应 PVE 的软件定义网络，入口在**集群运维 → SDN**。三层对象自上而下嵌套：

```text
区域（Zone） → VNet → 子网（Subnet）
```

虚拟机网卡里能直接选的是 **VNet**，所以至少要建到第二层，虚拟机才能桥接到 SDN 网络。

## 区域

区域决定转发方式，创建后**类型不可更改**。

| 类型 | 适用场景 | 必填字段 |
| --- | --- | --- |
| Simple | 简单二层，直接桥接到物理网桥 | 物理网桥（如 `vmbr0`） |
| VLAN | 基于 802.1Q 的 VLAN 隔离 | 物理网桥、VLAN 标签 |
| QinQ | 双层 VLAN，多租户隔离 | 物理网桥、外层 VLAN 协议 |
| VXLAN | 三层覆盖网络，跨网段 | VXLAN ID、对端地址 |
| EVPN | 带 BGP 控制面的 VXLAN | VXLAN ID、控制器、ASN |

「节点」留空表示该区域在所有节点生效；只填部分节点时，VNet 也只在这些节点上可用。

## VNet 与子网

VNet 必须归属某个区域，可以填别名方便识别，VLAN 标签留空由 PVE 自动分配。

子网负责地址规划：

| 字段 | 说明 |
| --- | --- |
| 子网（CIDR） | 如 `10.10.0.0/24`，创建后不可改 |
| 网关 | 通常是该网段第一个可用地址 |
| DHCP 起止 | 两端必须同时填或同时留空 |
| DNS 服务器 | 逗号分隔，可留空继承区域配置 |
| SNAT | 让该网段访问外部网络时做源地址转换 |

## 下发变更

对区域、VNet、子网的任何增删改，**都只是写进 pending 状态**，不会立刻作用到节点。页面顶部出现黄色提示条时：

- **下发配置**：把 pending 变更真正推到各节点，期间网络可能短暂中断。
- **丢弃变更**：放弃尚未下发的修改，回到上一次已生效的配置。

::: warning 下发会短暂影响网络
下发过程需要重建网桥与 OVS 配置，正在跑的虚拟机可能出现秒级丢包。生产环境建议避开业务高峰。
:::

::: tip 转发到其它节点不生效时
先确认该区域是否只在部分节点上启用，再检查节点的 `/etc/network/interfaces` 里是否已出现对应的 `vnet` 接口。两处任一不满足，VNet 都只能在本机看到。
:::
