# SSH 终端与文件管理

节点的 shell 直连统一走 SSH 窗口：一个窗口里可以同时开多个标签，右侧还能直接浏览和改动节点上的文件。终端本体始终在**独立窗口**中打开，主窗口里没有内嵌终端页。

## 打开方式

在主窗口「节点」页，点节点卡片上的「SSH 终端」按钮即可。新窗口使用自绘标题栏，可以最小化、最大化、关闭，也可以拖到第二块屏幕与主窗口并排。

> 连接沿用当前登录的 PVE 地址与账号密码，不需要另填一份。PVE 账号 `root@pam` 会映射为系统用户 `root`；HTTPS 面板使用 8006 时，SSH 默认走 22。
>
> 很多 PVE 节点只允许密钥 SSH（Debian 默认 `PermitRootLogin prohibit-password`），
> 这时密码登录会被拒绝。应用会**自动回退到 PVE 自己的节点通道（termproxy）**，
> 仍然用当前 PVE ticket 打开节点 Shell；该通道没有 SFTP，文件面板会隐藏。

## 虚拟机控制台

虚拟机的「更多操作」菜单和详情页「控制台」按钮都是二级菜单，可以选两种控制台：

| 类型 | 适合场景 | 走什么通道 |
| --- | --- | --- |
| VNC 控制台 | 需要图形界面、要看 BIOS / 安装引导 | PVE `vncproxy` + noVNC，独立控制台窗口 |
| xterm.js 终端 | 所有 QEMU 客户机的 shell（Windows / Linux / 其他） | 客户机 SSH 账号密码；LXC 仍走容器 pty |

选 xterm.js 时终端同样开在独立 SSH 窗口里，可以直接复用多标签；文件面板只在客户机 SSH 可用时显示。

> **QEMU 串口控制台已取消**：不再通过 `serial0` / `qm terminal` / PVE termproxy 打开 QEMU 终端，
> 所有 QEMU 客户机统一用 SSH 账号密码登录。没探测到客户机 IP 时，打开终端会先弹出凭据窗口手动填写。

### xterm.js 的通道

| 通道 | 标签 | 条件 | 能做什么 |
| --- | --- | --- | --- |
| 客户机 SSH | `SSH` | QEMU 运行中；客户机 sshd 可达或手动填地址 | 拿客户机自己的 shell，`whoami` 是客户机用户；文件面板进虚拟机内部 |
| 客户机 SSH（手动） | `SSH 手动` | QEMU 运行中，但 Guest Agent 未探测到 IP | 在凭据窗口里填 IP / 端口 / 账号 / 密码 |
| 容器 pty | `pty` | LXC 容器 | 容器终端；文件面板不可用 |
| PVE 节点通道 | `PVE` | 节点 Shell 的 SSH 密码/密钥不可用，但 PVE API 可登录 | 节点 Shell；没有 SFTP |

### 判定方式

QEMU 的 xterm.js 只看运行状态：

- **运行中**：始终可打开。客户机 22 端口可达时自动带出 IP；不可达/未探测时弹出手动凭据窗口；
- **未运行 / 模板**：置灰，先启动。

IP 探测靠 Guest Agent：读 `/agent/network-get-interfaces` 取出全部 IPv4（跳过 `127.`），
并发做 TCP 探活（1.2s 超时），第一个连上的就是客户机 IP。探测在后台跑，不阻塞列表刷新；
结果缓存 5 分钟，失败结果 2 分钟后重试，探测并发上限 4。

> Windows 虚拟机需要安装并启动 OpenSSH Server（或其它 SSH 服务）；Linux 需要 sshd。
> 没装也能打开窗口，但连接会提示 SSH 不可用。

不支持的项会**置灰**并在悬停时说明原因：

- QEMU 的 `vga` 设成 `none` / `serialN`，或 `vnc` 参数为 `0` → VNC 置灰；
- LXC 容器没有图形界面，VNC 恒置灰；它的 pty 天生存在，xterm 恒可用；
- 虚拟机和模板未运行时，两项都不可用，先启动再打开。

> 能力探测结果缓存 5 分钟；运行状态变化、或通过应用修改虚拟机配置后会立即重探。

## 客户机 SSH 凭据

所有 QEMU 客户机（Windows / Linux / 其他）统一使用客户机 sshd。窗口右上角的钥匙按钮可以填写：

- 主机、端口、账号、密码；
- 默认账号优先取 cloud-init 的 `ciuser`，没有时 Windows 用 `Administrator`、Linux 用 `root`；
- 密码框支持显示/隐藏；留空时依次尝试应用缓存的 cloud-init 密码、PVE 登录密码；
- 保存后**立即开一个新标签**，文件面板也同步使用这份凭据；
- QEMU 没探测到 IP 时，打开终端会先弹这个窗口，不会自动开一个必然失败的标签。

> PVE 的 cloud-init 配置接口**有意不回传 `cipassword`**，应用无法读取节点上已经存在的 cloud-init 密码。
> 因此密码只有两种来源：本应用写入 cloud-init 时缓存的加密副本，或用户在这个对话框里手动输入。
> 密码只保存在当前窗口内存，不落盘（cloud-init 缓存副本除外，走系统 safeStorage 加密）。

## 多标签终端

- 标签栏右侧的 `+` 新建会话，每个标签是一条独立 PTY；
- 同一标签切走再切回，**滚动历史不会丢**——终端实例常驻，只做显隐切换；
- 标签样式为扁平标签：选中项白底 + 底部深色下划线，关闭 `×` 在标签最左侧，仅选中或悬停时显示；
- 标签上的小圆点表示状态：绿=已连接、灰=已断开、黄=连接中、红=连接失败；
- 关闭标签或关闭整个窗口时，对应的 PTY 会一起回收，不会在主进程里留死连接。

窗口底部状态条显示当前会话的用户名、节点地址与标签总数。

## 文件面板

窗口右侧是 SFTP 文件面板，默认进入登录用户主目录。

**虚拟机终端窗口只允许浏览虚拟机内部**：

| 标识 | 含义 | 条件 |
| --- | --- | --- |
| `Administrator@10.10.12.204`（绿色） | 浏览**虚拟机内部**文件 | 终端走客户机 SSH，SFTP 复用同一个目标 |
| 无面板 +「文件：不可用（需客户机 SSH）」 | 不显示文件面板 | LXC pty / 尚未建立客户机 SSH |
| 无面板 +「文件：PVE 通道不支持」 | 不显示文件面板 | 节点 SSH 不可用，节点 Shell 回退到 PVE termproxy |

LXC pty 终端**不会**把 PVE 宿主机的 `/root` 当成容器目录。
节点 Shell 的 SSH 窗口是另一种窗口，走 SSH 时 `节点宿主机` 表示 PVE 节点文件；
回退到 PVE 通道时没有 SFTP，底部会标注「文件：PVE 通道不支持」。

> 客户机走的是 SFTP 登录用户：Linux 默认 `root`，Windows 默认 `Administrator`。
> 密码取终端窗口里填写的凭据（或缓存的 cloud-init 密码），和终端登录用的是同一份。

路径栏从左到右依次是：来源标识 → 上一级 → 刷新 → 面包屑。

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 浏览目录 | 点目录名 | 路径栏可逐级回退，`↑` 回上一级 |
| 预览 / 编辑 | 点文件名 | 文本文件直接在面板内编辑，改完点「保存」 |
| 新建文件 / 目录 | 工具行图标 | 在当前目录下创建 |
| 重命名 | 行悬停 → 铅笔 | 只改最后一段，前缀保持当前目录 |
| 删除 | 行悬停 → 垃圾桶 | 目录会递归删除，操作前二次确认 |
| 下载 | 行悬停 → 下载 | 弹出本地保存对话框 |
| 上传 | 工具行图标 | 弹出本地文件选择，上传到当前目录 |
| 搜索 | 工具行输入框 | 过滤当前目录，不递归 |

安全与边界：

- 所有路径都会被归一化，`../` 跳出用户主目录会直接报错；
- 超过 2 MB 的文件不加载内容，提示直接下载查看；
- 含 NUL 字节的文件判定为二进制，不以文本预览；
- 文件面板在窄窗口（< 1024px）自动收起，可用标题栏右侧按钮手动开关；
- SFTP 与终端复用同一条 SSH 连接（按 `主机:端口:用户` 缓存），不会为面板再握一次手。


## 连接失败时

错误会翻成可操作的中文提示，而不是原始套接字报错：

| 情况 | 提示 |
| --- | --- |
| 账号或密码错误 | SSH 登录 `user@host` 失败：账号或密码不正确；点钥匙图标重新填 |
| 客户机没开 SSH | 端口拒绝 / 超时；先在客户机安装 OpenSSH（Windows 还需启动服务） |
| 没探测到客户机 IP | 打开终端时直接弹凭据窗口，手动填 IP |
| 端口拒绝 | 无法连接 `host:22`：端口拒绝连接，请确认客户机已启动 SSH 服务 |
| 超时 | 连接 `host:22` 超时 |
| 域名解析失败 | 无法解析主机名 |

> 节点 Shell 仍会在节点 SSH 不可用时回退到 PVE 节点通道；
> 虚拟机终端不再回退串口，所有 QEMU 客户机统一走 SSH 账号密码。

## 按核负载与 SSH 的关系

总览与节点页的「CPU 负载」曲线上方是线程负载格子。按核占用率来自 SSH 读取节点 `/proc/stat`（一条命令取两次快照做差分），PVE 的遥测接口本身不提供逐核数据。

因此：

- SSH 不通时格子会显示占位色，并在标题处标注「SSH 未连接」；
- 只要节点开放 SSH 且账号可登录，格子会随 2 秒轮询自动刷新，无需手动打开终端窗口。
