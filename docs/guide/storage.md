# 存储管理

存储页对应 PVE 的 `Datastore` 权限域，管理的是**集群级存储定义**，不是单节点上的磁盘信息。

## 存储定义

列表展示集群中所有存储，含类型、内容类型标签、共享标记与停用状态。右上角「添加存储」支持常见类型：

| 类型 | 典型用途 | 必填 |
| --- | --- | --- |
| `dir` | 本地目录，存放 ISO / 备份 / 容器模板 | 路径 |
| `lvmthin` | 精简置备的虚拟机磁盘 | 卷组与 thin pool |
| `zfspool` | ZFS 存储池 | 池名称 |
| `nfs` / `cifs` | 网络共享 | 服务端与导出路径 |
| `iscsi` / `rbd` / `cephfs` | 块设备与分布式存储 | 目标或监视器 |

内容类型决定该存储能存什么：`images` 存虚拟机磁盘、`iso` 存安装镜像、`backup` 存 vzdump 归档、`vztmpl` 存容器模板。**没有勾选 `backup` 的存储不会出现在备份目标下拉框中**。

「限定节点」留空表示所有节点可用；填 `pve1,pve2` 则只在指定节点挂载。

::: warning 删除存储
删除存储定义只移除挂载配置，**不会删除底层数据**。若要清理卷，请先在「存储内容」里逐个删除。
:::

## 存储内容

在列表里点「浏览」，右侧面板会按节点读取该存储的卷：

- 顶部下拉可切换节点（同一存储在不同节点的内容可能不同）；
- 支持按卷名搜索；
- 每行显示卷名、大小、内容类型、VMID 与创建时间；
- 悬停行尾的垃圾桶图标可删除单个卷。

删除卷是一个提交到 PVE 的异步任务，卷会在后台释放，可到「任务」页查看进度。

## 资源池

资源池用于按业务把虚拟机与存储分组，便于 ACL 授权（给一个池授予 `PVEAdmin` 即可管理池内全部对象）。

- 「新建」填写池 ID 与备注即可创建；
- 删除资源池不会删除池内虚拟机，只是解除分组关系。
