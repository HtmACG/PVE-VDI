# 备份与还原

备份页把 PVE 的 `vzdump` 备份、归档管理与周期计划串在一起，不需要再登 Web 控制台。

## 立即备份

点右上角「立即备份」：

- **虚拟机 ID**：留空则备份所选节点的**全部**虚拟机；
- **备份模式**：
  - `snapshot` —— 在线快照，虚拟机继续运行，推荐；
  - `suspend` —— 短暂挂起后恢复；
  - `stop` —— 关机备份，最一致但会中断业务。
- **压缩算法**：`zstd` 压缩率与速度平衡最好，`none` 用于已经压缩过的数据；
- **只保留最近 N 份**：填 7 表示备份完成后自动清理更早的归档。

提交后返回 UPID，可在「任务」页看实时日志。归档大小通常与磁盘实际占用相关，精简置备的盘不会等于分配容量。

## 归档列表

扫描所有节点的、内容类型含 `backup` 的存储，汇总成一张表：

- 文件名、来源节点与存储、虚拟机类型（QEMU / LXC）、VMID、大小、创建时间；
- 支持按文件名或 VMID 搜索、按节点筛选；
- **还原**：以归档为基础创建一台新虚拟机（详见下节）；
- **删除**：直接删除归档文件，不可恢复。

::: warning 加密归档
带「加密」标记的归档需要在 PVE 端配置密钥才能还原，本工具不会代为输入密钥。
:::

## 还原

点「还原」后填写：

- **新虚拟机 ID**：必须未被占用，且 ≥ 100；
- **名称**：可选，留空沿用归档中的名称；
- **目标存储**：留空表示沿用归档所在存储；
- **生成新 MAC**：默认开启，避免与原机冲突；
- **还原后立即启动**：按需勾选。

还原同样是异步任务。LXC 归档会走容器创建接口，QEMU 归档走 `qmrestore`。

## 备份计划

列表展示 PVE 集群备份计划（`/cluster/backup`），字段包括计划表达式、范围、目标存储、模式与下次运行时间。

计划表达式使用 PVE 日历格式，常用写法：

```text
daily 02:00          # 每天凌晨两点
weekly sun 03:30     # 每周日凌晨三点半
monthly 1 04:00      # 每月一号四点
*/15                 # 每 15 分钟
```

「范围」可以是单台虚拟机（填 VMID）、单个节点，或者全部虚拟机。
