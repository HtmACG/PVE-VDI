# 集群与节点

总览看板集中展示集群状态、各节点资源水位、存储池容量与最近任务。

## 集群信息

页面顶部展示集群级别的关键信息：

- **Quorum**：集群法定票数状态，判断集群是否具备一致决策能力；
- **节点数量**：当前纳入集群的节点总数；
- **集群配置**：集群配置版本等信息；
- **HA 状态**：高可用服务与 HA 资源状态。

## 节点指标

每个节点卡片展示该节点的核心运行指标：

- CPU 使用率、内存使用率、根磁盘水位；
- 系统负载与运行时间；
- CPU 型号、KSM 状态；
- SSL 证书指纹。

### 2 秒独立刷新

服务器资源看板每 **2 秒**独立刷新一次，不等待完整集群数据返回，因此资源数字与时间戳接近实时。1 小时 RRD 曲线会在每次采样时实时追加当前数据点。

### 仪表盘读数

「服务器资源」区块的 CPU、内存、根磁盘三项用仪表盘呈现：

- 圆弧填充比例即当前占用率，指针指向同一刻度；
- 圆心下方是百分比读数，再下一行是绝对量与负载明细；
- 占用超过 **85%** 时圆弧与指针转为警示色，切换节点后数值带过渡动画；
- 仪表盘颜色取自当前主题变量，深浅色切换与强调色调整都会实时跟随。

### 线程负载格子

「CPU 负载」曲线正上方是一排小方块，一个方块对应一个物理线程，**方块数量就是核心数**：

| 负载区间 | 方块颜色 |
| --- | --- |
| 空载（≤ 2%） | 中性灰 |
| 轻载（2% ~ 35%） | 品牌色浅调 |
| 中载（35% ~ 60%） | 品牌色深调 |
| 高载（60% ~ 85%） | 警告黄 |
| 满载（≥ 85%） | 警示红 |

鼠标悬停单个方块可看到该线程的精确占用率，右侧 `n/N 忙` 统计的是负载高于 35% 的线程数。数据来自 PVE 的 `rrddata` 接口（`cpu0`…`cpuN` 字段），按 2 秒轮询刷新；节点未上报按核数据时，方块会退回中性灰占位，但仍按核心数画出正确数量。

## RRD 遥测曲线

节点 1 小时 RRD 遥测曲线来自 PVE 原生 `rrddata` 接口，用于观察短期内的资源趋势：

- 曲线按时间轴绘制，随采样自动追加；
- 数据源与 PVE 自带图表一致，不做二次推算。

## 存储池

展示各存储池的容量与属性：

- 总容量、已用空间与可用空间；
- 存储类型（如 LVM、LVM-Thin、目录、ZFS 等）；
- 是否为共享存储。
