# 产品简介

PVE VDI 是一个基于 Electron 的 Proxmox VE 桌面控制台，用于观察集群与节点状态、管理 QEMU / LXC 工作负载、查看虚拟机完整运行信息，并通过表单或模板克隆创建新虚拟机。

## 它能做什么

- **集群与节点监控**：Quorum、HA 状态、节点 CPU / 内存 / 磁盘水位、存储池容量与最近任务，资源看板每 2 秒独立刷新。
- **工作负载管理**：QEMU 虚拟机与 LXC 容器的搜索过滤、电源操作、详情查看、关机配置与磁盘管理。
- **内置控制台**：QEMU 使用 noVNC 图形控制台，LXC 与节点 Shell 使用 xterm.js 终端，均在独立原生窗口中打开。
- **节点设置**：硬件信息与温度传感器、网络接口编辑、DNS、时区、证书、防火墙与存储查看。
- **镜像管理**：ISO 浏览、本地流式上传、URL 导入与删除。
- **创建虚拟机**：空白创建或从模板完整 / 链接克隆。

## 设计语言

界面采用 shadcn/ui 设计语言与 Radix 原语，全局 **0px 圆角**。信息层级以数据为主：

- 放大的资源指标、克制的分隔线与等宽数字；
- 状态只用文字表达，不使用多余的指示色块；
- 登录页带主题插画，界面字体与强调色可在设置中自定义。

## 隐私原则

为避免泄露内部环境，公开仓库不包含真实集群截图、服务器地址、虚拟机名称、IP、证书指纹或本地路径。

- 源码中的 PVE 地址与用户名默认值为空；
- 会话票据仅保存在主进程内存，密码默认不落盘；
- 真实环境截图仅保存在本地，不进入仓库。

## 版本与协议

当前版本 **1.7.0**，基于 **GPL-3.0-only** 协议开源。
