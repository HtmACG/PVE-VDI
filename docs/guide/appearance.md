# 外观与设置

设置页提供界面外观定制、背景管理、更新检查与开机自启等选项。

## 主题

- 支持深色 / 浅色主题切换；
- 登录页使用独立插画，跟随主题与强调色变化。

## 自定义背景

支持分别自定义登录页背景与软件主界面背景：

- 背景图片保存在本机应用数据目录；
- 可在设置中选择、预览和清除；
- 不上传到任何远端。

## 界面字体

提供四种字体选项：

| 选项 | 说明 |
| --- | --- |
| Inter | 默认无衬线字体 |
| 系统字体 | 跟随 Windows 系统界面 |
| JetBrains Mono | 等宽字体，含中文回退 |
| 自定义 | 输入任意 CSS `font-family` |

## 强调色

提供六种预设强调色：

- Windows 蓝（默认 `#0078d4`）；
- 信号蓝、青绿、紫罗兰、玫红、工业橙；
- 也支持输入任意 `#RRGGBB` 自定义颜色。

字体与强调色会持久化到本地设置，并实时同步到已打开的控制台窗口（通过主进程广播设置变更），
控制台窗口内切换主题也会反向作用于主窗口。

::: tip 为什么状态色不变
配色只调整强调色，不改动状态色和资源预警色，避免降低状态信息的可读性。
:::

## 可视化设置

- 切换网络接口的“卡片 / 列表”展示形态；
- 空内容使用官方空状态插图，连接失败使用网络断开图标。

## 更新检查

设置页提供：

- GitHub Release / Tag 更新检查；
- 更新日志查看；
- 开发者信息。

版本比较使用 semver，不会在后台自动下载或安装。

## 开机自启

开启后，登录 Windows 会自动启动 PVE VDI：

- 仅注册当前用户的登录项；
- 不保存密码，不提升权限。

## 桌面通知

设置页的「桌面通知」卡片用 Windows 通知中心提醒两类集群事件，窗口收起到托盘时同样生效：

- **虚拟机关机**：虚拟机从运行变为已停止时提醒，同一轮里多台关机合并为一条；
- **任务失败**：PVE 任务以失败状态结束时提醒，新任务失败会合并计数；
- 总开关关闭后仍会记录状态但不弹通知，重新打开不会补发旧事件；
- 「发送测试通知」可确认系统通知未被 Windows 通知设置或「专注助手」拦截。

首份集群快照只作为基线，登录前就已关机或失败的记录不会在启动时集中弹出。

## 托盘常驻

关闭主窗口不会退出软件，只是把窗口收起到系统托盘，后台继续保留连接与控制台会话：

- 点击托盘图标、或双击托盘图标即可重新打开主窗口；
- 托盘右键菜单提供“打开主窗口”与“退出 PVE VDI”；
- 只有选择“退出 PVE VDI”才会真正结束进程、注销 PVE 会话并关闭所有控制台窗口；
- 重复启动程序会直接唤起已运行的实例，不会再开第二份。
